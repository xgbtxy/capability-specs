# Environment Setup

这个能力要解决的是：先把页面现场喂给 AI，再让 AI 反推测试用例和触发路径。

## 1. 必要材料

- 页面截图、页面描述或关键 URL
- 至少一份当前功能现场材料

## 2. 强烈建议补充的材料

- 抓包文件
- 关键 JS 文件
- 页面里可见的角色、状态、按钮、输入框说明

## 3. 默认环境

- Windows
- PowerShell

## 4. 和这个能力的关系

- 这不是让 AI 从零开始逛站
- 这是先让人把最值钱的现场交给 AI
- 再让 AI 设计更像样的测试输入和操作路径

## 5. 常见问题

- 问题：只给一句功能描述，AI 建议太空
  排查：补页面截图、按钮说明、输入框、角色和当前状态
- 问题：抓不到关键数据包
  排查：先让 AI 补更多边界值、状态切换和操作顺序
